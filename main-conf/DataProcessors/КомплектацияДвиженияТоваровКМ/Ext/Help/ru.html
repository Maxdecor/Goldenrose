Процесс оприходования и реализации маркированного товара.

 

1.      Загрузка КМ товара (всей партии) в систему 1С на момент эмиссии кодов маркировки.

 

Выгрузка файла маркированного товара из персонального кабинета «ASL Belgisi» в формате CSV и загрузка данных в 1С.

Описание процесса:

Первичный ввод кодов маркировки.

Открываем документ «Первичный ввод кодов маркировки».

Табличная часть документа – очищена.

 Команда «Загрузка из CSV».

Выбираем файла маркированного товара из персонального кабинета «ASL Belgisi» в формате CSV.

Из файла заполняются данные маркированного товара. Соответствие по базе номенклатуры в 1С и реквизиту GTIN из файла. 

Команда «Записать комплектацию»

Происходит сверка правильности ввода данных из файла.

В окне «Служебные сообщения» отображается процесс обработки результата загрузки.

 

 

 Коды сообщений:

·                Строка [порядковый номер] КМ [код_маркировки] – Записан > КМ записан в базу 1С.

·                Строка [порядковый номер] КМ [код_маркировки] – Есть ошибки > КМ НЕ Записан в базу 1С, требуется проверка файла загрузки.

 

2.      Поступление маркированного товара

 

Загруз- Загрузка КМ товара в систему 1С на момент поступления товара на склад.

    Описание процесса:

 На основании документа поступления товара открываем документ ввод кодов КМ. Как из самого документа ПТУ, так и из общего журнала документов  поступления.

 Открываем документ «Ввод кодов маркировки».

 Шаги по заполнению такие же как в Варианте 1.

 Возможно сканирование кодов, построчно с помощью сканера штрихкодов.  Для этого в открытом документе по регистрации кодов маркировки в поле КМ  отображается сканируемый код.

 

 Проверка по раннее введенным кодам присутствует(Служебное поле).

 При построчном вводе можно сразу вводить коды коробок (если присутствуют, чтобы потом их использовать при вводе кодов в документах поступления и  реализации.

 После ввода всех КМ по данному ПТУ следует команда «Записать комплектацию»

 При записи производится проверка введенных кодов на соответствие с выбранным документом по коду GTIN и количеству.

 

 3.      Реализация маркированного товара

 Комплектация при реализации товаров производится аналогично поступлению.

 После открытии документа ответственное лицо по складу (Кладовщик) вносит (сканирует КМ товара), посредством сканера штрихкода, товарную единицу.

 Если отпускается неполная коробка, то недостающие коды можно отсканировать поштучно.

 После того как кладовщик завершил отбор товара по кодам маркировки завершаем обработку документа командой «Записать комплектацию». При записи  проверяется соответствия количеству план-факту реализации, кодов маркировки. В случае отклонений выдается сообщение об ошибки.

 ВАЖНО!

 При изменении документов прихода/расхода необходимо также выбрать режим ввода на основании. Программа проверит статус кодов и, если был расход,  выдаст информацию(сообщит) о документах реализации. Затем нужно последовательно отменить расход, потом приход.
